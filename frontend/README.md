# 📚 Question Papers Repository - Mumbai University

A comprehensive web application for browsing and downloading question papers from Mumbai University across various courses and semesters.

## 🎯 Features

- **Multi-Course Support**: BA, BSc CS, BSc IT, BCom, BMS, MA, MSc, MCom
- **Semester-wise Organization**: 6 semesters for each course
- **Year-wise Archives**: Question papers from 2018-2024
- **Subject-wise Categorization**: Organized by individual subjects
- **PDF Integration**: Direct viewing and downloading of question papers
- **Search Functionality**: Quick search across all courses
- **Responsive Design**: Mobile-friendly interface
- **User Authentication**: Login and registration system

## 🏗️ Project Structure

```
Question-Paper/
├── index.html              # Main landing page
├── courses/                # Course selection pages
├── semester/               # Semester selection pages
├── year paper/            # Year-wise question papers
├── subject-QP/            # Individual subject question papers
├── auth/                  # Authentication pages
├── css/                   # Stylesheets
├── media/                 # PDF files and media
└── README.md              # Project documentation
```

## 🚀 Getting Started

### Prerequisites
- Modern web browser with PDF support
- Local web server (for development)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/Question-Paper.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Question-Paper
   ```

3. Open `index.html` in your web browser or serve using a local server.

## 🎨 Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Styling and responsive design
- **JavaScript**: Interactive functionality and search
- **Bootstrap 5**: UI framework and components
- **PDF.js**: PDF viewing capabilities

## 📱 Usage

1. **Browse Courses**: Start from the main page to select your course
2. **Select Semester**: Choose the semester you need
3. **Pick Year**: Select the academic year
4. **View Subjects**: Browse available subjects
5. **Download/View**: Access question papers in PDF format

## 🔍 Search Functionality

Use the search bar on any page to quickly find:
- Course names
- Semester information
- Subject titles
